💬 What is an LLM?

A Large Language Model (LLM) is a deep learning model trained on massive amounts of text (trillions of tokens) to predict the next most likely word/token. The emergent result is a system that can write, reason, code, translate, and converse at near-human level.

🎯 Core Insight:

A model trained to predict text with enough data and compute also learns world knowledge, reasoning, math, code, and logic as byproducts. Intelligence emerges from prediction at scale.

🔤 Step 1: Tokenization

LLMs don't read words — they read tokens. Tokens are chunks of text (subwords, words, or characters) mapped to IDs. GPT-4 uses ~100K tokens; the average word is ~1.3 tokens.

🔍 How "Hello World!" is tokenized:
Hello  World !
🔢 Token IDs:
9906 3146 0

Each token ID maps to a row in the model's embedding matrix (a lookup table of vectors).

⚙️ How LLMs Generate Text
🔤

1. Tokenize

Input text split into tokens and converted to integer IDs.

📐

2. Embed

Each token ID → high-dimensional vector (e.g. 4096-dim for GPT-4) via embedding lookup.

👁️

3. Attention

Self-attention layers relate each token to all others, building contextual representations.

🧮

4. Transform

Many stacked Transformer blocks process the representations (GPT-4 has ~120 layers).

🎲

5. Sample

Final layer outputs probability distribution over all tokens. Sample next token using temperature.

🔁

6. Repeat

Add sampled token to context and repeat until end-of-sequence token is generated.

✍️ Prompt Engineering

The art of crafting inputs to get the best outputs from LLMs. Key techniques:

 prompt_patterns.txt
SYSTEM: You are an expert Python developer. Be concise and precise.

USER (Zero-Shot):
Write a function to reverse a linked list.

USER (Few-Shot with examples):
Classify sentiment. Positive/Negative/Neutral:
"Great product!" → Positive
"Terrible service" → Negative
"It arrived today" → ?

USER (Chain-of-Thought):
Solve step by step: A bat and ball cost $1.10 total.
The bat costs $1 more than the ball. What does the ball cost?
Think through this carefully before answering.

ASSISTANT: Let me think step by step...
🎯 Top Prompt Tips:
  • Be specific — vague prompts get vague answers
  • Give examples (few-shot) for complex formats
  • Ask it to think step-by-step (Chain-of-Thought)
  • Assign a role: "You are an expert in..."
  • Specify output format: JSON, bullet list, table
  • Use temperature=0 for deterministic, factual answers
