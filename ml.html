📊 What is Machine Learning?

Machine Learning is a subset of AI where programs learn from data instead of being explicitly programmed. Rather than writing rules, you show the machine examples and it figures out the rules itself.

❌ Traditional Programming

Data + Rules → Answers
You write every rule by hand.

✅ Machine Learning

Data + Answers → Rules
The machine finds the rules.

🗂️ 3 Types of Machine Learning
🏷️ Supervised
Labeled data. You give the model input+answer pairs. It learns to predict answers for new inputs.

Like a student with an answer key.

Uses: Email spam, price prediction, image classification, medical diagnosis.
🔍 Unsupervised
No labels. The model finds hidden structure and patterns in raw data on its own.

Like a student exploring without a teacher.

Uses: Customer segmentation, anomaly detection, recommendation systems, topic modeling.
🎮 Reinforcement
Trial and error. An agent takes actions, gets rewards or penalties, and learns what to do.

Like training a dog with treats.

Uses: Game playing (AlphaGo), robotics, trading bots, self-driving cars.
⚙️ Key ML Algorithms
📉 Linear Regression
Fits a straight line through data to predict continuous values. Simple but powerful for many real-world problems.
Use: House price prediction, sales forecasting
🔀 Logistic Regression
Despite the name, it's for classification! Outputs probability (0-1) of a category. Fast and interpretable.
Use: Spam detection, disease diagnosis (yes/no)
🌳 Decision Tree
Splits data using yes/no questions, like 20 questions. Highly interpretable — you can visualize every decision.
Use: Loan approval, fraud rules, customer churn
🌲 Random Forest
An ensemble of many decision trees. Each tree votes, and the majority wins. Much more robust than a single tree.
Use: Credit scoring, feature importance analysis
🚀 Gradient Boosting (XGBoost)
Builds trees sequentially, each one fixing the errors of the last. Often wins Kaggle competitions.
Use: Ranking, search relevance, structured data
📍 K-Nearest Neighbors
"You are who your neighbors are." Classifies by finding the K most similar examples in training data.
Use: Recommendation, anomaly detection, image recognition
⚔️ SVM
Support Vector Machine finds the best boundary (hyperplane) between classes, maximizing margin.
Use: Text classification, bioinformatics, face detection
🎯 K-Means Clustering
Unsupervised. Groups data into K clusters by minimizing distance to cluster centers. Iterates until stable.
Use: Customer segmentation, image compression

⚠️ Overfitting vs Underfitting
😰 Underfitting
Model is too simple. Fails to capture the pattern even in training data. High bias, low variance.

Fix: More complex model, more features, less regularization.
😊 Just Right
Model captures the true pattern. Generalizes well to new data. Good balance of bias and variance.

Goal: Cross-validation, proper train/val/test split.
😵 Overfitting
Model memorizes training data including noise. Works great on training, fails on new data. High variance.

Fix: Regularization (L1/L2), dropout, more data, simpler model.
🐍 Quick Python: ML in 10 Lines
 sklearn_example.py
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

# 1. Load data
X, y = load_iris(return_X_y=True)

# 2. Split into train/test
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# 3. Train model
model = RandomForestClassifier(n_estimators=100)
model.fit(X_train, y_train)

# 4. Evaluate
preds = model.predict(X_test)
print(f"Accuracy: {accuracy_score(y_test, preds):.2%}") # → ~97%

💡 ML Metrics
Accuracy
% of correct predictions
Precision
True positives / all positives predicted
Recall
True positives / all actual positives
F1 Score
Harmonic mean of precision & recall
AUC-ROC
Area under classifier curve
